# veoskill: промо-ролик (исходники)

Готовый ролик: **[Releases → v17](https://github.com/swensi17/veoskill-promo/releases/tag/v17)**
- `veoskill-promo-v17-ru.mp4`: русская версия, полное качество, 1920x1080, 60 fps, 4 мин 15 с, со звуком;
- `veoskill-promo-v17-uz.mp4`: узбекская версия (новый латинский алфавит), то же качество;
- `-phone.mp4`: лёгкие копии для телефона и мессенджеров (около 27 МБ).

Скачать проект: зелёная кнопка **Code → Download ZIP** или `git clone https://github.com/swensi17/veoskill-promo.git`.

Ролик сделан кодом на Remotion (React). Любую сцену можно поправить в коде и сразу увидеть результат в браузере, как dev-режим сайта.

## Что сделать на новом ноутбуке (коротко)

1. Распакуй архив в простую папку без пробелов и кириллицы, например `C:\work\veoskill-promo`.
2. Открой эту папку в Claude Code (desktop app, вкладка Code) и напиши агенту:
   > Прочитай AGENT.md и подготовь проект к работе.

   Агент сам поставит всё нужное (Node.js, ffmpeg, Python и пакеты) и проверит сборку.
3. Чтобы посмотреть ролик вживую и править: попроси агента **«открой Remotion Studio»**. В браузере откроется ролик с таймлайном: можно листать, ставить на паузу и говорить, что поправить. Правка видна через секунду, рендер для этого не нужен.
4. Когда всё нравится: **«сделай финальный рендер»**. Файл появится в `out/veoskill-promo.mp4`.

## Команды (для агента или терминала, из папки проекта)

| Команда | Что делает | Время |
|---|---|---|
| `npm install` | ставит зависимости (один раз) | 1–3 мин |
| `npm run dev` | Remotion Studio: живой просмотр и правки, http://localhost:3000 | сразу |
| `node scripts/build.mjs --list` | таблица сцен (номер, имя, секунды) | сразу |
| `node scripts/build.mjs --scene 6` | одна сцена в 540p для проверки -> `out/scene-6.mp4` | ~1 мин |
| `node scripts/build.mjs --draft` | весь ролик в 540p со звуком -> `out/draft.mp4` | ~3–5 мин |
| `node scripts/build.mjs` | финал 1080p 60 fps со звуком -> `out/veoskill-promo.mp4` | ~15–25 мин |

Как работать быстро: правишь в Studio, смотришь сразу, при сомнении рендеришь одну сцену. Полный рендер делаешь один раз, в конце.

Подробности для агента: `AGENT.md`. Правила оформления: `docs/RULES.md`.
