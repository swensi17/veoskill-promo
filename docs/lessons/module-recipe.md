# Как мы делаем модуль урока (рецепт по «Трудовому праву»)

Модуль 18 «Трудовое право» - первый, доведённый до конца по этим правилам (ноябрь 2026). Следующие модули делаем так же.

## Из чего состоит модуль

Папка `api/content/legal/module-NN/`:
- `lessons/урок-NN.txt` - теория урока: экраны теории по раундам (коронам);
- `games.json` - игры урока (`gamesByLesson[N-1].games[]`), у игры `config.crown` (раунд 1-3) и `config.screen` (к какому экрану теории она относится);
- `locales/ru.json`, `en.json`, `uz.json` - все тексты по ключам `legal.mNN.*`;
- картинки: `web/public/comics/mNN/strips/` (полоски, см. `docs/comics/README.md`).

## Как идёт урок (алгоритм)

1. Экран «Что будем изучать»: список тем урока (3-5 пунктов) и «Какой результат».
2. Раунды (короны): первый лёгкий, второй сложнее, третий - эксперт. Повторить урок можно с любого раунда (кнопка «Повторить» → список раундов).
3. В раунде: **экран теории → его игры** («поток 3-2-1», `packages/exercise-core/src/screen-flow.ts`). Игры проверяют только то, что объяснено на этом экране и раньше.
4. Сначала **лёгкие игры на узнавание**: «Выберите ответ», миф, пары, пропуск, «Соберите фразу».
5. Потом **игры-ситуации с комиксом-полоской**: чат-история, «Что будет, если…», казус, «Рассудите спор». Они не стоят первыми в уроке.
6. Ошибки повторяются в конце урока. Экран конца: опыт, точность, время, «Обзор урока» (плитки: тип задания, вопрос при наведении, ваш ответ по нажатию) и «Далее».

## Правила текстов (проверяем каждый урок)

- Порядок тем по нарастающей, как у репетитора: нельзя проверять то, чего ещё не проходили.
- Термин вводится строкой «==Термин== - это …» в теории. Сайт подсвечивает его в играх и показывает подсказку. Термин - настоящий юридический (не «простой», который совпадает с «просто», а «время простоя»).
- В вопросе **4 варианта**, один верный. Все примерно одной длины: верный не должен угадываться по длине или подробности.
- Пояснение «почему» есть и у верного, и у неверного ответа. Номер статьи пишем, только если он есть в теории этого урока; номера не придумываем, тексты закона - из lex.uz.
- Только короткий дефис «-», никаких «—» и «–». Время - «22:00».
- Простые слова, короткие фразы. Имена героев внутри одной игры одинаковые.
- en и uz по смыслу такие же, как ru.

## Как проверяли (аудит)

Два раза по всем 36 урокам, параллельно двумя агентами (уроки 1-18 и 19-36):
1. Порядок тем, забегания вперёд, тяжёлые игры не первыми, лёгкие игры на экраны, где были только тяжёлые (добавлено 26).
2. Тексты: термины, длина ответов, опечатки, тире, переводы. Найдено и исправлено 13 мест в уроках 1-18 и 3 в уроках 19-36.

## Как заливать (локально)

```bash
cd api
npm run -s db:import-module -- legal-module-18     # теория
npm run -s db:import-locales -- legal-module-18    # тексты (после этого перезапустить локальный API: он держит тексты в памяти)
npm run -s db:import-games -- legal-module-18      # игры
# поднять ContentVersion, чтобы сайт взял новое
```

Проверка на `http://localhost:3000`, вход `http://localhost:3000/api/dev/guest?locale=ru`. Тест полосок всех видов: первый урок модуля 34 «Комиксы».

## Выкладка на прод (когда модуль готов)

Только по прямой команде владельца:
1. `scripts/sync.sh`, `scripts/check-build.sh` (сайт и API собираются).
2. Пуш в `main` → сервер сам соберёт и обновит сайт (`scripts/auto-update.sh`).
3. Контент модуля в базу прода: сначала `pg_dump` базы, потом те же три импорта на сервере (`docs/ops/deploy.md`, раздел «База данных»).
4. Проверить `https://veoskill.uz/ru` и пару уроков модуля.

## Не проверено в модуле 18

- Номера статей в части казусов и пояснений (например 144, 165, 174, 266, 312, 313-315, 333, 545, 560) не сверены с lex.uz.
- Имена героинь в текстах и Азиз на полосках (см. `docs/comics/README.md`).
