# Алгоритмы обучения VEOSKILL (по образцу модуля «Трудовое право»)

Все модули делаем по этим правилам. Образец - модуль 18 «Трудовое право» (ноябрь 2026). Рядом: `module-recipe.md` (файлы и заливка), `agent-lessons.md` (подробная инструкция агенту), `docs/comics/README.md` (комиксы).

## 1. Строение модуля

1. **Блоки по 4 урока с теорией**, затем **урок-проверка** (каждый 5-й: 5, 10, 15, 20, 25, 30, 35).
   - Урок с теорией: новое знание на 3-5 тем.
   - Урок-проверка: **без теории**, только игры по решениям всех 4 прошлых уроков. Сначала узнавание, потом ситуации (казус, спор). Так человек сам вспоминает, а не перечитывает.
2. **Финальное большое дело** (в «Трудовом праве» урок 36 «Большое дело Дилнозы»): одна длинная история на весь модуль.
3. Темы идут от простого к сложному, как у репетитора: что такое право → договор → время и деньги → отпуск → дисциплина → увольнение → защита прав.
4. Модуль самодостаточен: в нём объяснено всё, что он проверяет.

## 2. Ход одного урока

1. **«Что будем изучать»**: 3-5 тем урока и строка «Какой результат».
2. **Раунды (короны) 1-3.** Первый лёгкий, второй сложнее, третий - эксперт. Пройденный урок можно повторить с любого раунда.
3. **Раунд всегда начинается с теории.** Экран теории → его игры → следующий экран теории → его игры («поток 3-2-1», `packages/exercise-core/src/screen-flow.ts`). Игра проверяет только то, что уже объяснено на этом экране и раньше.
4. **После первого экрана теории вплетены повторения старых уроков** (раздел 3).
5. **Ошибки в конце урока**: каждый неверный шаг возвращается, пока не будет верного ответа.
6. **Экран конца**: опыт, точность, время, «Обзор урока» (плитки: тип задания, вопрос при наведении, ваш и верный ответ по нажатию) и «Далее».

## 3. Повторение старого (интервальное)

В урок N сами подмешиваются игры из старых уроков (`web/src/lib/path-recall.ts`):

| Какой урок возвращается | Зачем |
|---|---|
| N-1 (вчерашний) | закрепить свежее |
| N-3 | первое забывание |
| N-7 | неделя спустя |
| N-10, N-20, … | дальнее: на каждом раунде свой |

- Из ближнего урока берутся быстрые игры (свайп, «Соберите фразу»), из дальних - миф и выбор ответа. На 3-м раунде урока с тестами - вопросы экзамена самых старых уроков.
- Раунд 1: два повтора после первого экрана теории и ещё в конце. Раунды 2-3: один повтор.
- В начале модуля, пока дальних уроков нет, берутся самые первые.

Плюс вне уроков: раздел **«Повторение»** собирает слабые места человека (`/hub/review`).

## 4. Порядок игр по сложности

1. **Узнавание** (первыми): «Выберите ответ», «Найди миф», «Найдите пары», «Заполните пропуск», «Соберите фразу», свайп.
2. **Применение**: «Найдите ошибку», «Шаги», «Шкала», «Статья», «Документ».
3. **Ситуации с комиксом** (не первыми в уроке): чат-история, «Что будет, если…», казус, «Рассудите спор».

## 5. Правила текстов

- Термин вводится строкой «==Термин== - это …». Сайт сам подсвечивает его в играх и показывает подсказку. Термин - настоящий юридический («время простоя», а не «простой», который совпадает с «просто»).
- Нельзя проверять то, чего ещё не объяснили.
- В вопросе 4 варианта, один верный, все примерно одной длины, неверные правдоподобные.
- Пояснение «почему» есть и у верного, и у неверного ответа. Статья - только та, что есть в теории урока. Номера статей не придумываем, текст закона из lex.uz.
- Только короткий дефис «-». Простые слова, короткие фразы. Имена героев в одной игре одинаковые. en и uz по смыслу как ru.

## 6. Комиксы

- Полоска на 3 кадра без текста в каждой игре-ситуации. Главный герой - Азиз, герои всегда из образцов во Flow.
- Рецепт пошагово: `docs/comics/README.md`.

## 7. Мотивация

Опыт (XP) за шаги, точность и время урока, короны за раунды, «золотой» урок за бонусное задание без ошибок, серия дней, задания дня.

## 8. Почему этот алгоритм хорош

1. **Вспоминание сильнее перечитывания.** Человек не читает правило второй раз, а сам достаёт его из памяти в игре. Так знание держится дольше.
2. **Интервалы против забывания.** Старое возвращается в N-1, N-3, N-7, N-10 уроков, как раз когда начинает забываться.
3. **Урок-проверка каждые 4 урока** собирает блок в одно целое и показывает, что осталось слабым, без подсказки теорией.
4. **От лёгкого к сложному.** Сначала узнать слово, потом применить, потом решить живую ситуацию. Нет провала «сразу тяжело».
5. **Ситуации и комиксы** переносят закон в жизнь: человек видит своего героя и своё решение, а не голую статью.
6. **Сразу видно, почему.** Пояснение после каждого ответа, ошибки возвращаются в конце, «Обзор урока» показывает итог.
7. **Одинаковые правила во всех модулях**: агенты делают новые модули по одному рецепту, качество ровное, проверять проще.

## 9. Как делать новый модуль

1. План тем от простого к сложному, блоки по 4 урока + проверка каждый 5-й, финальное дело.
2. Теория уроков с терминами «X - это …» и статьями из lex.uz.
3. Игры по раундам: на каждый экран теории сначала узнавание, потом применение, ситуации ближе к концу.
4. Уроки-проверки: только игры по блоку, без теории.
5. Аудит в два прохода (порядок и логика; тексты и термины), ru/en/uz.
6. Полоски для игр-ситуаций по `docs/comics/README.md`.
7. Заливка и проверка локально, потом прод по `module-recipe.md`.
