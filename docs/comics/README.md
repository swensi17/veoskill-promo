# Комиксы-полоски для игр: как делать (пошагово)

Этот файл - готовый рецепт. По нему мы сделали полоски для всего модуля 18 «Трудовое право» (ноябрь 2026) и так же делаем следующие модули.

## Что такое полоска и где она стоит

- Одна широкая картинка: **3 кадра одной ситуации подряд**, между кадрами тонкие белые полосы (4 px), без рамки вокруг.
- **Без текста на картинке**: ни букв, ни облачков с репликами, ни вывесок. Текст печатает сайт поверх картинки. Поэтому одна картинка годится для ru, en и uz.
- Стоит только в 4 видах игр, где есть ситуация с людьми: **чат-история** (`story`), **«Что будет, если…»** (`branch`), **казус** (`kazus`), **«Рассудите спор»** (`court`). В остальных играх (выбор ответа, миф, пары, пропуск и т. д.) полосок нет.
- Путь в игре: `config.img` в `api/content/legal/<модуль>/games.json`, файл лежит в `web/public/comics/<модуль>/strips/lNN-<вид>.webp` (например `l12-story.webp`).
- На сайте полоска показывается в одной форме 2,4 : 1 с обрезкой по центру (`web/src/exercise/game/variants/comic-strip.tsx`), в казусе - в одной карточке с текстом случая (`kazus-case.tsx`).

## Герои (одинаковые везде)

Во Flow в проекте сохранены образцы персонажей. Всегда берём их как **reference**, а не описываем словами заново, иначе лица гуляют.

| Образец во Flow | Кто | Как выглядит |
|---|---|---|
| Aziz | главный герой почти всех полосок | молодой узбек, тёмные волосы, тюбетейка, тёмно-синее поло с бейджем |
| Boss | работодатель, директор, начальник | седой мужчина в тёмном пиджаке и белой рубашке |
| Mother | кадровик, бухгалтер, другие женщины | женщина в лиловом платке |
| Judge | судья | судья в мантии |
| Son | ребёнок (только где по сюжету нужен ребёнок) | мальчик |

Правило владельца: **в большинстве полосок главный - Азиз**. Если в тексте игры героиня (Дилноза, Камила и т. д.), это расхождение: либо меняем имя в тексте, либо рисуем женщину (см. «Что осталось»).

## Шаг 1. Подготовка

1. Открыть Flow в **встроенном браузере** окна Claude (там быстрее, чем через расширение Chrome).
2. Владелец сам входит в свой Google-аккаунт, где лежит проект с героями. Агент в аккаунты не входит и пароли не вводит.
3. Открыть проект с героями во Flow. Если Flow пишет «Проект не найден», открыт другой аккаунт: в адресе нужен номер нужного аккаунта (`/u/<номер>/`).
4. Модель картинок: Nano Banana (во Flow), одна картинка за запрос (`x1`).

## Шаг 2. Список полосок

1. Взять все игры `story / branch / kazus / court` модуля без `config.img`:

   ```bash
   node -e "const g=require('./api/content/legal/module-18/games.json');g.gamesByLesson.forEach((l,i)=>l.games.forEach(x=>{if(['story','branch','kazus','court'].includes(x.variant)&&!x.config.img)console.log(i+1,x.slug)}))"
   ```
2. Для каждой игры прочитать её тексты (`locales/ru.json` по ключам игры) и теорию урока (`lessons/урок-NN.txt`).
3. Придумать **три сцены этой ситуации по порядку**: завязка, что случилось, чем решилось. Сцены в разных местах или моментах, если история движется.

## Шаг 3. Запрос во Flow

1. Прикрепить нужных героев из образцов (кнопка «+» у поля запроса → персонажи проекта).
2. Текст запроса (на английском, по шаблону):

   ```
   Wide horizontal comic strip, exactly three equal panels side by side, separated by thin white gutters,
   detailed hand-drawn comic illustration with clean ink lines and soft muted colours, modern Tashkent, Uzbekistan.
   The same characters look identical in all three panels.
   Aziz (from the reference) is <роль>; Boss (from the reference) is <роль>.
   Panel 1: <сцена 1>. Panel 2: <сцена 2>. Panel 3: <сцена 3>.
   Absolutely no text: no letters, no words, no speech bubbles, no captions, no signs with writing;
   papers and screens show only scribbles. No emblems, flags or logos.
   ```
3. Запросы идут **подряд, без пауз**: как только картинка готова, сразу следующий запрос. Можно держать два в работе (вторая вкладка). Остановиться и сказать владельцу, только если Flow показал ошибку, лимит, вход или капчу.

## Шаг 4. Скачать картинку

Flow не даёт сохранить файл без диалога, поэтому на время работы запускаем маленький приёмник на этом компьютере:

```bash
node docs/comics/tools/recv.cjs <папка-для-сырых-картинок>   # слушает 127.0.0.1:4789
```

На странице Flow (через инструмент выполнения JS в браузере) картинка отправляется POST-запросом на `http://127.0.0.1:4789/?n=l12-story.webp`, и она ложится в папку. После работы приёмник остановить.

## Шаг 5. Нарезка в полоску

```bash
uv run --no-project --with pillow python -I docs/comics/tools/strip.py <сырая.webp> web/public/comics/<модуль>/strips/lNN-<вид>.webp
```

Скрипт сам находит 3 кадра по светлым промежуткам, срезает внешние поля и тонкие рамки, собирает кадры рядом с белыми полосами 4 px. Если пишет `NO_GUTTERS`, Flow нарисовал не три кадра: перерисовать.

## Шаг 6. Проверить глазами (обязательно)

Каждую полоску открыть и посмотреть:
- ровно 3 кадра, сцены про **эту** игру и в правильном порядке;
- Азиз и остальные похожи на образцы, одинаковые во всех кадрах;
- **нет текста**: вывесок, надписей «MENU», «WARNING», букв на бумагах. Есть - перерисовать;
- нет лишних рук, кривых лиц.

## Шаг 7. Вставить в игры и залить

1. Прописать `config.img` каждой игре (`"/comics/<модуль>/strips/lNN-<вид>.webp"`).
2. Залить в локальную базу:

   ```bash
   cd api
   npm run -s db:import-games -- legal-module-18
   npx prisma db execute --file <cv.sql> --schema prisma/schema.prisma   # поднять ContentVersion, чтобы сайт взял новое
   ```
3. Открыть пару уроков на `http://localhost:3000` и посмотреть полоски в игре.
4. Коммит по ~10 уроков: картинки + `games.json`.

## Что сделано (модуль 18 «Трудовое право»)

- Полоски у всех 56 игр `story / branch / kazus / court` в уроках 1-36. 51 новая (уроки 4-36), 5 старых в уроках 1-3.
- Коммиты: `ecc0a8ed5`, `1b9c8c89c`, `44d58b62f` (финальная перерисовка с образцами героев).
- Урок 37 и модуль 34 - тестовые полноэкранные комиксы (отдельная игра `comic`), это другая вещь.

## Что осталось

1. **Имя в тексте и герой на картинке**: во многих играх героини Дилноза, Камила, Шахноза, Лола, а на полоске Азиз. Решить: переименовать в текстах или перерисовать эти полоски с героиней.
2. **Уроки 1-3**: старые полоски с другими героями, перерисовать по этому рецепту.
3. В уроках 11, 13, 16, 27 нет игр-ситуаций, значит и полосок нет.
