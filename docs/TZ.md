# ТЗ: продолжение работы над промо-роликом veoskill (версия v17, черновик)

Это задание для Claude Code на компьютере владельца (Mac). Владелец не программист: отвечай по-русски, коротко и простыми словами. Сначала прочитай полностью `AGENT.md` и `docs/RULES.md`, правила из RULES.md обязательны.

## 1. Как работать

- Главное: **живой просмотр в Remotion Studio**, без рендера после каждой правки. Запусти `npm run dev` (или `.claude/launch.json`, сервер `studio`) и открой Studio во встроенном браузере Claude, композиция **VeoskillV11**. Владелец смотрит там и говорит правки.
- Полный рендер (`node scripts/build.mjs`) только когда владелец скажет. Перед сдачей проверка агентом по кадрам, как в `AGENT.md`, раздел 7.
- Ничего не публикуй наружу без явного «да» владельца.

## 2. Первая настройка на Mac

```bash
brew install node ffmpeg python@3.12
npm install
python3 -m pip install -r requirements.txt
node scripts/build.mjs --list
```

Если `brew` нет, поставь Homebrew (https://brew.sh) или Node/ffmpeg/Python с официальных сайтов. В `requirements.txt` теперь есть `pyloudnorm`: без него падает мастеринг звука.

Переменная `REMOTION_BROWSER` нужна только в облаке (там нельзя скачать браузер Remotion). На Mac её не задавай: Remotion сам скачает Chrome Headless Shell при первом рендере.

## 3. Что сделано в v17 (по сравнению с v16)

1. **Новая музыка:** Mixkit №1303 (`audio/assets/music/mk-1303.mp3`), 125 BPM, плотный бит. Владелец выбрал её из 8 вариантов. Лицензия та же, Mixkit Free (`audio/LICENSES.md`). Старый трек `mk-371.mp3` лежит в папке, но не используется.
2. **Каждая смена сцены попадает на удар музыки.** Длины сцен в `SCENES` (`src/V11.tsx`) подогнаны так, что начала сцен лежат на сетке `2.8 + k*28.8` кадра (1 удар = 28,8 кадра = 0,48 с). Если меняешь длину сцены, меняй её на целое число ударов (28,8 кадра, с округлением), иначе склейки уйдут с бита. Проверка: `node scripts/build.mjs --list` и посчитать, что каждое начало минус 2,8 делится на 28,8 с точностью до кадра.
3. **Музыка в `audio/mix.py`:** трек идёт целиком под этой сеткой. В начале фильтр «раскрывает» звук до первого слова (S2). На входе в финальную сцену S11 трек сдвигается на целое число ударов (сейчас назад на 3 удара), чтобы последний удар трека пришёлся примерно через 2,4 с после начала S11 (логотип и QR). Сдвиг считается сам из длины ролика.
4. **Слова-перебивки в такт:** у `Words` в S2, LessonWords, S9, OurWords `per={43.2}` (1,5 удара), у S7 `per={57.6}` (2 удара).
5. **Звуки интерфейса:** добавлено около 60 звуков (клики, появления, «правильно», свист) по всем сценам. Списки `clicks`, `pops`, `CH`, `WH` в `audio/mix.py`, формат `(номер_сцены_с_0, кадр_внутри_сцены)`.
6. **Счётчик 1 608 (Counter, `src/V11Parts.tsx`):** «ЗАКОНЫ И КОДЕКСЫ» теперь просто белый заголовок, без рамки и синей точки.
7. **«Обычно закон выглядит так» (LexScene, `src/V11.tsx`):** справа 5 красных пунктов под подписью «НА LEX.UZ», потом каждый переворачивается в зелёную галочку под подписью «В VEOSKILL». Тексты в `LEX_ROWS`. Сцена стала 317 кадров.
8. **«Чем мы удобнее» (Table, `src/V11.tsx`):** 8 строк вместо 4, появляются на полуударах. Тексты в `ROWS`. Сцена стала 288 кадров.
9. `scripts/stills.mjs` понимает `REMOTION_BROWSER` (только для облака).

Длина ролика теперь 101,08 с (6065 кадров). Таблица сцен в `AGENT.md` (раздел 4) относится к v16: точные кадры смотри через `--list`.
